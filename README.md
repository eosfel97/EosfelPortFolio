# anygnahiet.dev — Portfolio

Portfolio personnel de Any Gnahiet, développeur full-stack.

Construit avec [Astro](https://astro.build).

## Stack

- **Framework** : Astro 6 (SSG, îlots React pour les démos interactives)
- **Langues** : Français et Anglais
- **TypeScript** : strict
- **Styles** : CSS custom (design tokens)

## Développement local

Node.js >= 22.12 requis.

```bash
cp .env.example .env
npm install
npm run dev
```

Le serveur démarre sur `http://localhost:4321`.

## Commandes

| Commande | Action |
|---|---|
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production dans `dist/` |
| `npm run preview` | Prévisualiser le build |
| `npm run lint` | Vérifier le code (ESLint) |
| `npm run format` | Formater le code (Prettier) |
